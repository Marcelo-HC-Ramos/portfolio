PROJETO INTEGRADOR I · FATEC COTIA

Portal da Transparência — Terceiro Setor Cotia

Projeto acadêmico e cívico desenvolvido em equipe na FATEC Cotia, em colaboração com a Prefeitura de Cotia, para tornar mais claros e acessíveis os dados sobre repasses públicos às Organizações da Sociedade Civil.

Abrir portal ↗ Power BI ↗

O problema

O projeto parte da necessidade de disponibilizar de forma clara e organizada informações sobre repasses financeiros destinados ao Terceiro Setor em Cotia, facilitando acompanhamento, fiscalização e análise por cidadãos e gestores.

Como os dados foram trabalhados

01 · Fonte

Dados públicos oficiais, principalmente do Painel de Transferências do TCE-SP.

02 · Tratamento

Limpeza, filtragem e análise exploratória inicial com Python e Microsoft Excel.

03 · Visualização

Dashboards interativos desenvolvidos em Microsoft Power BI.

04 · Portal

Integração dos dashboards em uma interface web com HTML, CSS e JavaScript.

05 · Áreas

Administração, Assistência Social, Cultura, Desporto e Lazer, Educação, Legislativo, Saúde e Urbanismo.

06 · Impacto

Transformação de dados públicos em informação visual para transparência e controle social.

Tecnologias

Python

Tratamento, limpeza e análise exploratória.

Excel

Organização e apoio ao tratamento dos dados.

Power BI

Dashboards e visualização interativa.

HTML / CSS / JavaScript

Construção do portal que apresenta os dashboards.

Meu aprendizado

Este projeto amplia meu portfólio porque mostra a aplicação do ciclo de dados em um contexto público: partir de uma fonte oficial, preparar os dados, construir indicadores e comunicar os resultados em uma interface acessível. Também evidencia trabalho em equipe e integração entre análise de dados, BI e desenvolvimento web.

Equipe

O portal informa uma equipe de seis alunos de Ciências de Dados da FATEC Cotia e orientação acadêmica do Prof. André Roberto Ramos dos Santos. O projeto foi realizado em colaboração com a Prefeitura Municipal de Cotia.
