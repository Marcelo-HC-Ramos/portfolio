CASE 01 · PYTHON / STREAMLIT

Sentimento Político

Aplicação interativa desenvolvida para explorar análise de sentimentos em conteúdo político e transformar dados textuais em visualizações e interpretações.

Abrir aplicação online ↗

Stack

Python + Streamlit

Foco

Análise de sentimentos e exploração visual.

Entrega

Aplicação web interativa.

O que este projeto demonstra

Dados textuais

Trabalho com conteúdo não estruturado para gerar sinais analisáveis.

Interface

Uso do Streamlit para levar a análise para uma aplicação acessível.

Comunicação

Apresentação de resultados de forma visual e explorável.

Complemento técnico — Database Opinate

Como complemento ao projeto, foi desenvolvido um banco relacional em MySQL 8+ para estruturar usuários, propostas, comentários, votos, comunidades e parlamentares. O modelo utiliza chaves estrangeiras, tabelas de relacionamento, triggers para atualização de contadores e índices para apoiar as consultas.

Modelagem

Entidades relacionadas por chaves primárias e estrangeiras, incluindo propostas, usuários, comentários e parlamentares.

Automação

Triggers atualizam automaticamente contadores de votos positivos e negativos.

Desempenho

Índices adicionais foram criados em campos utilizados nos relacionamentos e consultas.
