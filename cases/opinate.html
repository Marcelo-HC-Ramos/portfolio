CASE 05 · MYSQL 8+

Database Opinate

Modelagem relacional para uma plataforma de participação cidadã, com usuários, propostas, comentários, votos, comunidades e parlamentares.

Abrir código SQL

Integridade

Primary keys, foreign keys, UNIQUE e CHECK.

Automação

Triggers para atualizar contadores de votos.

Performance

Índices em campos usados nas consultas e relacionamentos.

Exemplo de estrutura

CREATE TABLE proposal ( id CHAR(36) PRIMARY KEY, title VARCHAR(255) NOT NULL, user_id CHAR(36), municipality_id INT NOT NULL, score INT AS (upvotes_count - downvotes_count) STORED ); CREATE INDEX idx_proposal_user ON proposal(user_id);

O que este projeto demonstra

Modelagem

Separação de entidades e relacionamentos para organizar o domínio.

Regras

Restrições que ajudam a manter consistência dos dados.

Automação

Triggers para manter métricas sincronizadas com votos.
