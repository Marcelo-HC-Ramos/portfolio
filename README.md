## Como publicar no GitHub Pages

1. Crie um repositório público, por exemplo `portfolio`.
2. Envie os arquivos desta pasta para a raiz do repositório.
3. No GitHub, abra `Settings` → `Pages`.
4. Em "Build and deployment", selecione `Deploy from a branch`.
5. Escolha a branch `main` e a pasta `/root`.
6. Salve e aguarde a publicação.

O botão do portfólio já aponta para o formato de URL do Colab via GitHub. Se você publicar o portfólio em outro nome de repositório, basta trocar o nome do repositório no link.
